# What is this?
This repository contains my MJML email designs, including source code, generated HTML files, and preview screenshots.

I'm using this repo as a place to practice, experiment, and improve my email development skills over time.

## What is MJML?
MJML is a framework that simplifies responsive email development and helps make emails more compatible across different clients.

You can learn more about it here:
https://documentation.mjml.io/#mjml-guide

## Can I use your code for my emails?
Absolutely.

Feel free to use, modify, or learn from anything in this repository. No credit is required.

That said, I'd genuinely love to hear if you end up using something from here, just out of curiosity :)
